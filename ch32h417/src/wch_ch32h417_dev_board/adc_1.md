# CH32H417/CH32H415 ADC 零基础入门教程
（理论+寄存器+实操 全流程，适配新手）
> 适用芯片：沁恒 RISC-V 系列 **CH32H417 / CH32H415**
> 阅读前提：零基础嵌入式开发者、会基本单片机 IO 操作，无需深厚寄存器基础

---

## 前言
ADC（模数转换器）作用：**把模拟电压 → 单片机可识别的数字数值**。
生活中电池电压、热敏电阻、电位器、各类模拟传感器，全都依赖 ADC 采集。
CH32H417/CH32H415 集成**双路 12 位高速 ADC**，功能丰富、配置逻辑统一，本教程从「是什么→基础概念→寄存器解读→标准配置→代码实操→常见问题」一步步讲解。

---

# 一、ADC 基础认知（先懂概念，再动手）
## 1.1 什么是模拟量 & 数字量
- **模拟量**：连续变化的电压（0~VDDIO），比如电位器输出、电池电压、温度传感器电压，电压可以是 1.2V、2.56V 等任意值。
- **数字量**：单片机只能识别 0/1，必须把连续电压**量化成整数**，这个转换过程就是 **ADC 采样**。

## 1.2 芯片 ADC 整体硬件参数（H417/H415 通用）
1. **位数**：12 位 ADC
   - 12 位 = 最大数值 \(2^{12} = 4096\)，采样范围：**0 ~ 4095**
   - 分辨率含义：把参考电压分成 4096 等份，数值越大，电压精度越高。
2. **时钟**：ADC 内核时钟 ADCCLK 最高 **80 MHz**
3. **通道数量**：总计 18 路采样源
   - 外部通道：ADC_IN0 ~ ADC_IN15（16 路，外接模拟传感器）
   - 内部通道：
     - ADC_IN16：片内温度传感器
     - ADC_IN17：内部参考电压 \(V_{REFINT}\)
4. **输入电压范围**：\(V_{SS} \le V_{IN} \le V_{DDIO}\)
   - 简单理解：输入电压不能超过芯片 IO 供电电压，不能低于地。
5. **特色功能**
   - 可编程增益 PGA（放大小信号）
   - 硬件自动校准（提升采样精度）
   - 模拟看门狗（电压上下限报警）
   - DMA 自动搬运数据
   - 软件/定时器/外部引脚 多种触发方式
   - 双 ADC 同步/交替采样（仅 H417 双 ADC 架构）

## 1.3 两大核心分组（重中之重）
CH32H 系列 ADC 把所有通道分为**规则组**和**注入组**，分工完全不同，新手**优先只用规则组**。

### （1）规则通道组（日常 90% 场景使用）
- 最多支持 **16 路通道** 顺序采集
- 支持：单次采集、连续采集、扫描采集、DMA、中断
- 用途：常规电压采集、多路传感器巡检、长时间连续采样

### （2）注入通道组（紧急中断采集）
- 最多支持 **4 路通道**
- 优先级高于规则组，可打断正在进行的规则组采样
- **不支持 DMA**，多用于突发异常信号检测
- 新手前期可以暂时不学

## 1.4 关键时间公式（必须记住）
单通道一次完整转换时间：
\[
T_{CONV} = \text{采样时间} + 12.5 \times T_{ADCCLK}
\]
- 采样时间：开发者可自由配置（多个时钟周期可选）
- \(T_{ADCCLK}\)：ADC 内核时钟周期

> 经验：高精度采集 → 加长采样时间；高速采集 → 缩短采样时间。

## 1.5 电压换算公式（直接套用）
设：
- `ADC_Val`：采样得到的数字值（0~4095）
- `V_REF`：参考电压（一般等于 \(V_{DDIO}\)）

\[
V_{IN} = \frac{ADC\_Val}{4095} \times V_{REF}
\]
示例：参考电压 3.3V，采样值 2048

\[
V_{IN} = \frac{2048}{4095} \times 3.3 \approx 1.65\ \text{V}
\]

# 二、ADC 工作模式与触发方式（协议/逻辑层）
## 2.1 五大常用工作模式
### 1）单次单通道模式（入门首选）
- 动作：触发一次 → 采集一次数据 → 停止
- 特点：配置最简单、功耗低
- 适用：单点电压、电池检测、低速传感器

### 2）连续单通道模式
- 动作：启动后**不间断循环采样**，直到软件关闭
- 适用：动态电压、波形监测、高频信号采集

### 3）扫描模式（多通道批量采集）
- 动作：按预先设置的通道顺序，自动依次采集所有通道
- 分：单次扫描 / 连续扫描，搭配 DMA 实现全自动多路采集
- 适用：多路模拟传感器同时采集

### 4）间断模式
- 把一组通道拆分成多小组，每次触发只采一组
- 限制：规则组、注入组**不能同时开启间断模式**

### 5）双 ADC 模式（CH32H417 专属）
ADC1 为主、ADC2 为从，支持同步采样、交替采样，采样速率翻倍。
包含：同步规则、同步注入、快速交替、慢速交替等子模式。

## 2.2 触发源（怎么让 ADC 开始采样）
ADC 启动方式分为两大类：
### 1）软件触发（新手首选）
代码里写指令直接启动转换，简单稳定，适合绝大多数入门项目。

### 2）硬件外部触发
由片上定时器、外部中断引脚启动采样，适合**定时精准采样**场景：
- 定时器 1/2/3/4/8 捕获/溢出事件
- 外部中断引脚 EXTI11、EXTI15

> 规则组、注入组拥有独立触发源，可分开配置。

## 2.3 数据对齐方式
ADC 12 位数据存放在 16 位寄存器中，提供两种对齐：
1. **右对齐（推荐新手）**
   12 位有效数据靠右侧，高位补 0，读取数值可直接代入电压公式。
2. **左对齐**
   数据靠左，多用于特殊运算，入门不推荐。

## 2.4 附加功能说明
1. **PGA 可编程增益**
   支持 ×1 / ×4 / ×16 / ×64 倍放大，专门用来采集**微弱小信号**，开启增益必须同时开启 ADC 输入缓冲。
2. **模拟看门狗**
   设置电压上限、下限，采样值超出范围自动置标志位/触发中断，用于过压、欠压保护。
3. **低功耗模式**
   - 正常模式：高功耗，支持 6MHz 以上采样
   - 低功耗模式：省电，仅支持 2MHz 以下低速采样，适合电池产品
4. **片内温度采集**
   通道 IN16 对应内部温度传感器，可读取芯片内部温度。

# 三、核心寄存器讲解（结合功能，新手看得懂）
> 说明：寄存器按「初始化流程顺序」讲解，不罗列无用位；地址以手册标准为准，`ADCx` 代表 ADC1 / ADC2。

## 3.1 整体初始化顺序（固定流程，所有模式通用）
1. 开启 GPIO、ADC 外设时钟 → 配置 ADCCLK 分频
2. ADC 上电（ADON 位）→ 等待稳定
3. 执行 ADC 硬件校准（必做，保证精度）
4. 配置通道序列、通道数量
5. 配置每个通道独立采样时间
6. 配置工作模式、对齐方式、触发源
7. 开启 DMA / 中断（按需）
8. 软件/硬件启动转换 → 读取结果

---

## 3.2 关键寄存器逐段解读
### 1）ADC 状态寄存器 `ADCx_STATR`（偏移 0x00）
作用：查询 ADC 当前工作状态、标志位。
重点位：
- **EOC**：规则组转换结束标志 → 1=采集完成
- **JEOC**：注入组转换结束标志 → 1=采集完成
- **AWD**：模拟看门狗报警标志
- **STRT / JSTRT**：规则/注入转换正在进行标志

> 使用逻辑：查询 `EOC=1`，再去读采样数据。

### 2）控制寄存器 1 `ADCx_CTLR1`（偏移 0x04）
模式、增益、看门狗、双 ADC 模式全部在此配置：
1. **PGA[1:0]**：增益选择 00(×1) / 01(×4) / 10(×16) / 11(×64)
2. **BUFEN**：输入缓冲使能（开增益必须开启）
3. **SCAN**：扫描模式总开关（1=开启多通道扫描）
4. **DISCEN / JDISCEN**：规则/注入间断模式开关
5. **JAUTO**：自动注入模式
6. **AWDEN / JAWDEN**：规则/注入通道看门狗使能
7. **DUALMOD[3:0]**：双 ADC 模式选择（仅 ADC1 有效）
8. 各类中断使能位：`EOCIE`、`JEOCIE`、`AWDIE`

### 3）控制寄存器 2 `ADCx_CTLR2`（偏移 0x08）【最核心】
ADC 启停、校准、触发、对齐、DMA、低功耗全部在此：
1. **ADON**：ADC 模块总开关
   - 0：断电休眠（几乎不耗电）
   - 0→1：ADC 上电唤醒
   - 已为 1 时再写 1：**软件启动转换**
2. **CONT**：连续模式开关
   - 0：单次模式
   - 1：连续循环采样
3. **CAL**：启动 ADC 校准位（软件置 1，校准完成硬件自动清 0）
4. **RSTCAL**：复位校准寄存器（校准前必须先复位）
5. **CAL_AUTO**：硬件自动偏移校准
6. **ALIGN**：数据对齐
   - 0：右对齐（推荐）
   - 1：左对齐
7. **DMA**：DMA 功能开关（仅规则组有效）
8. **ADC_LP**：低功耗模式开关
9. **EXTTRIG / JEXTTRIG**：外部触发使能
10. **EXTSEL / JEXTSEL**：选择具体硬件触发源
11. **SWSTART / JSWSTART**：软件启动位

### 4）采样时间寄存器 `ADCx_SAMPTR1 / SAMPTR2`
每个通道可以**单独配置采样时钟周期**：
可选档位：1.5 / 7.5 / 13.5 / 28.5 / 41.5 / 55.5 / 71.5 / 239.5 个 ADCCLK。
> 实用建议：
> - 高精度采集：选大周期（如 239.5）
> - 采样率 > 1MHz：不要低于 3.5 周期

### 5）规则通道序列寄存器 `ADCx_RSQR1 / RSQR2 / RSQR3`
作用：定义**多通道扫描顺序 + 通道总数**
- `L[3:0]`：规则组一共多少个通道（1~16）
- `SQx[4:0]`：第 N 个转换对应的通道编号（0~17）

### 6）注入通道序列寄存器 `ADCx_ISQR`
- `JL[1:0]`：注入组通道总数（1~4）
- `JSQx[4:0]`：注入通道编号

### 7）数据寄存器
1. **规则数据寄存器 `ADCx_RDATAR`**
   存放规则组最终采样值，16 位，右对齐时直接读取低 12 位。
2. **注入数据寄存器 `ADCx_IDATAR1~4`**
   注入组采样结果，会自动减去偏移寄存器 `IOFRx` 设定值。

### 8）看门狗阈值寄存器
- `ADCx_WDHTR`：电压高阈值
- `ADCx_WDLTR`：电压低阈值
采样值超出区间则 AWD 标志置 1。

# 四、实操手把手：标准初始化 + 代码逻辑（新手可直接移植）
## 4.1 硬件接线（以单通道 IN0 采集电位器为例）
1. 电位器一端接 3.3V，一端接 GND
2. 电位器中间抽头 → CH32H417/H415 `PA0`（ADC_IN0）
3. 芯片正常供电 3.3V

## 4.2 整体配置思路（文字流程）
以 **「单次单通道、软件触发、右对齐、不启用增益」** 最基础模式为例：
1. 开启 GPIOA 时钟、ADC1 时钟，配置 PA0 为模拟输入
2. 配置 ADC 分频，保证 ADCCLK ≤ 80MHz
3. 置 `ADON=1` 唤醒 ADC，等待稳定
4. 复位校准寄存器 → 启动校准 → 等待校准完成
5. 设置数据右对齐、关闭连续模式、关闭扫描模式
6. 设置规则组通道数量 = 1，选择通道 IN0
7. 设置通道 0 采样时间
8. 软件启动转换
9. 查询 EOC 标志，读取采样值，计算电压

## 4.3 关键代码伪代码（通用逻辑，适配 WCH 官方库）
```c
// 1. 时钟 + GPIO 初始化
RCC->APB2PCENR |= RCC_APB2Periph_GPIOA;
RCC->APB2PCENR |= RCC_APB2Periph_ADC1;
// 配置 PA0 模拟输入
GPIOA->CFGLR &= ~(0x0F << (0*4)); 

// 配置 ADC 分频（保证 ADCCLK < 80MHz）
RCC->CFGR0 &= ~RCC_ADCPRE;
RCC->CFGR0 |= RCC_ADCPRE_DIV2;

// 2. ADC 上电唤醒
ADC1->CTLR2 |= ADC_ADON;
Delay_us(10);  // 等待稳定时间

// 3. ADC 校准（必做）
ADC1->CTLR2 |= ADC_RSTCAL;
while(ADC1->CTLR2 & ADC_RSTCAL); // 等待复位完成

ADC1->CTLR2 |= ADC_CAL;
while(ADC1->CTLR2 & ADC_CAL);   // 等待校准完成

// 4. 基础模式配置
ADC1->CTLR2 &= ~ADC_CONT;    // 单次模式
ADC1->CTLR2 &= ~ADC_ALIGN;    // 右对齐
ADC1->CTLR1 &= ~ADC_SCAN;     // 关闭扫描模式

// 5. 规则组配置：1个通道，通道0
ADC1->RSQR1 &= ~ADC_L;
ADC1->RSQR1 |= (1-1) << 20;  // 通道总数 = 1
ADC1->RSQR3 &= ~ADC_SQ1;
ADC1->RSQR3 |= 0 << 0;       // 第1个转换：通道0

// 6. 设置通道0采样时间（举例：7.5周期）
ADC1->SAMPTR2 &= ~ADC_SMP0;
ADC1->SAMPTR2 |= ADC_SMP0_7_5CYC;

// 7. 读取采样函数
uint16_t ADC_Read(uint8_t ch)
{
  ADC1->CTLR2 |= ADC_SWSTART;   // 软件启动转换
  while( !(ADC1->STATR & ADC_EOC) ); // 等待转换结束
  return ADC1->RDATAR;          // 返回采样值
}

// 8. 主循环调用
uint16_t adc_val;
float voltage;
while(1)
{
  adc_val = ADC_Read(0);
  voltage = adc_val * 3.3f / 4095.0f; // 换算电压
  // 打印/使用 voltage
}
```

## 4.4 多通道扫描模式简要配置改动
只需修改 3 处：
1. `ADC1->CTLR1 |= ADC_SCAN;` 开启扫描模式
2. `L[3:0]` 设置为实际通道数量
3. 在 `RSQR` 寄存器依次填写所有通道编号
4. 配合 DMA 可实现自动连续读取

# 五、片内温度采集（特色功能实操）
1. 开启内部参考与温度传感器：`ADC1->CTLR2 |= ADC_TSVREFE`
2. 采样通道选择 **IN16**
3. 推荐采样时间：17.1us
4. 温度计算公式：
\[
Temp(^\circ C) = \frac{V_{SENSE} - V_{25}}{Avg\_Slope} + 25
\]
- \(V_{25}\)：25℃ 时传感器电压（参考芯片手册电气参数）
- \(Avg\_Slope\)：温度斜率（mV/℃）

> 提示：片内温度适合观察**温度变化**，做精准测温建议外接传感器。

# 六、新手常见问题 & 排错（高频踩坑点）
1. **采样值一直为 0 / 最大值**
   - 排查：GPIO 是否设为**模拟输入**、接线是否断路、参考电压是否正常。
2. **数据跳动大、精度差**
   - 原因：**未做 ADC 硬件校准** / 采样时间太短 / 输入信号无滤波电容。
3. **ADCCLK 超过 80MHz**
   - 现象：ADC 工作异常、死机；解决：增大分频系数。
4. **注入组使用 DMA 无效**
   - 特性：注入组本身**不支持 DMA**，改用规则组。
5. **间断模式开启后采集异常**
   - 禁止：规则、注入组不能同时开间断模式。
6. **低功耗模式采样率上不去**
   - 原因：低功耗模式仅限 2MHz 以下采样，高速场景关闭 `ADC_LP`。
7. **增益开启后数据不对**
   - 检查：是否同时开启 `BUFEN` 输入缓冲。
